Floréal Technologies construit des logiciels ouverts. Notre code source est
public, nos formats sont ouverts, et les données que nos outils écrivent
restent lisibles sans nous.

## Ce que nous fabriquons

[MediaCopy 3000](@/projects/mediacopy3000.fr.md) déplace les médias d'une caméra
entre les volumes de stockage et vérifie chaque copie face à un manifeste ASC
MHL. C'est le premier de nos outils ; la [page des projets](@/projects/_index.fr.md) les
liste tous.

## Nous joindre

Le code est sur [GitHub](https://github.com/Floreal-Technologies), et les
manuels sont sur [docs.floreal.tech](https://docs.floreal.tech). Ouvrez un
ticket dans le dépôt de l'outil que vous utilisez.
