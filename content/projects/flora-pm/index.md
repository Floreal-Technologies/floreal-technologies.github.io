Flora.pm is an alternative package index for the whole Haskell ecosystem.

It indexes packages from package repositories like Hackage and Cardano,
and creates a more ergonomic experience for Haskellers browsing the ecosystem.

<!-- more -->

---

Flora.pm is a project made in collaboration with
[Guérilla.Studio](https://guerilla.studio) to create the best interface to
browse Haskell packages.

## Ambitions

Flora.pm has been an ambitious project since its inception in 2021.

We want to make **the best** interface to browse Haskell packages, no less.
As web development professionals in the Open-Source ecosystem,
we have a desire to improve the experience of Haskell developers in their
daily interactions with the ecosystem.

This is combined with a particular care for matters of ecosystem security.
Recent years have seen an increasing amount of attacks targeting open-source
packages and their maintainers, and so we are focused on protecting
both package maintainers and users.
